## 知识门户需求完善（草案）

### 目标与角色
* 目标：构建面向企业/组织的知识门户，覆盖知识生产、评审、发布、检索与运营分析全流程。
* 角色：作者、评审人、发布管理员、普通读者、系统管理员、运营分析师。

### 1. 知识提交、评审与发布流程（文件级别）
* 提交入口：支持上传文件（PDF/Word/Markdown/图片/音视频等），或在线编辑并保存为文件。
* 元数据：标题、摘要、关键词/标签、分类、所属部门、业务线、保密级别、语言、有效期、来源。
* 流程：提交 → 机器预检（格式/敏感信息/完整性）→ 评审（多人并行/串行）→ 发布或退回修订 → 归档。
* 评审能力：批注、对比、必填意见、超时提醒、代理审批、评审记录留痕。
* 通知与待办：站内通知/邮件/企业IM，可配置提醒频率与升级策略。

### 2. 发布知识的版本、权限、更新与退出管理
* 版本管理：支持主版本/次版本，变更说明、版本对比、回滚。
* 权限管理：按用户/组织/角色/项目/标签控制访问，可设置保密级别与水印。
* 更新机制：定期复审提醒、过期提示、强制更新/替换、历史版本归档可查。
* 退出（下架）机制：下架原因、下架审批、可设置保留期；支持软删除与永久删除。

### 3. 自动标签、分类与摘要
* 自动标签：基于NLP/LLM生成初始标签，支持人工确认与纠错。
* 分类体系：按客户提供的分类与标签字典进行映射与校验（包含同义词/禁用词）。
* 摘要提炼：提供“短摘要（<=150字）+长摘要（<=500字）”，支持多语言。
* 质量控制：置信度评分、低置信度提示人工复核、模型版本与生成记录可追溯。

### 4. 知识目录展示
* 目录层级：支持多级分类树、专题合集、热门主题。
* 浏览视图：列表/卡片/树状结构切换，支持排序（时间/热度/评分）。
* 快速预览：摘要、作者、更新时间、版本、权限提示。

### 5. 检索与问答界面
* 关键词检索：拼写纠错、同义词扩展、筛选（标签/分类/时间/作者/权限）。
* 语义检索：向量检索+关键词检索混合排序，权重可配置。
* 问答：可对单篇文档或多文档进行问答，展示引用片段与来源。
* 反馈闭环：搜索结果满意度、问答命中率、无结果反馈入口。

### 6. 运营监控与统计分析（含信息收集点）
* 埋点采集：页面访问、搜索词、点击、停留时长、下载、收藏、分享、点赞/踩、问答对话。
* API监控：调用量、响应延迟、错误率、QPS、资源消耗、模型成本统计。
* 知识热点：热门主题、热门文档、趋势变化、周期对比。
* 检索效果：点击率、零结果率、二次搜索率、问答准确率/拒答率。
* 知识缺口分析：高频搜索无结果、重复提问主题、内容更新建议。
* 报表与看板：按部门/人群/时间维度生成报告，支持导出（Excel/PDF）。

### 交互与体验补充
* 全局导航与面包屑，支持收藏与最近浏览。
* 多语言与无障碍支持（可选）。
* 移动端适配或轻量H5入口。

### 非功能性要求
* 安全：权限审计、访问日志、内容水印、敏感词与脱敏。
* 性能：高并发检索、缓存策略、异步索引构建。
* 可运维性：日志、告警、备份、灾备。
* 可扩展：支持外部知识源接入（API/同步任务/爬取白名单）。
